Learning & Mentoring

IT・プログラミングを、
分かるところから一緒に。

中学生・高校生・大学生・就活生・社会人まで、現在の知識と目的に合わせて個別に進めます。学校の授業の補助、IT分野の学び直し、資格学習、実際に手を動かす練習、IT職を目指す相談などに対応します。オンライン全国対応です。

Support

年齢ではなく、目的に合わせて。

一般教科の家庭教師ではなく、IT・コンピュータ・プログラミング・AIを中心とした個別指導です。

中学生・高校生

パソコンやプログラミングを基礎から学びたい方へ。

  • PC・インターネットの基礎
  • プログラミング入門
  • 生成AIの安全な使い方
  • 興味に合わせた小さな制作

大学生・就活生

授業の理解、技術力の底上げ、IT職を目指す準備を支援します。

  • Python / C / Javaなどの基礎
  • Linux・Git / GitHub・ネットワーク
  • ポートフォリオ・学習計画の相談
  • IT職の技術面接・就活準備の相談

社会人・学び直し

仕事で必要になったITやAIを、目的に合わせて学びます。

  • Python・自動化
  • Linux・ネットワーク・セキュリティ
  • 生成AIの実務活用
  • 情報処理技術者試験の学習相談

進め方

一律の教材を押し付けず、現在地と目標を確認して内容を決めます。

  • 単発の質問・相談
  • 数回の短期集中
  • 継続的な学習サポート
  • 手を動かす演習・レビュー

学年、興味がある分野、学校や独学でどこまで進んでいるか、何が分からないかが分かれば、進め方を提案します。
