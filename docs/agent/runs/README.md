# Session & milestone records

One Markdown file per accepted milestone, e.g. `2026-11-10-WEB-20261110-01.md`.
Use headings `Baseline`, `Changed`, `Verification`, `Agents used`, `Decisions`, `Risks`, `Next step`.
Only write observed commands and results. Commit a report with the implementation after review, unless sensitive. Never store complete chat transcripts or private internal reasoning.
